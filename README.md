## Prototype details  
Outside of this code, the prototype uses:  
- Raspberry Pi
- Stepper Motor with motor driver
- USB Hub with USB Cameras (https://no.rs-online.com/web/p/raspberry-pi-cameras/2473234)
- Reality Capture for Photogrammetry (https://www.realityscan.com/en-US/news/realityscan-20-new-release-brings-powerful-new-features-to-a-rebranded-realitycapture)
